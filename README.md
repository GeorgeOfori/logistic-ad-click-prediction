# Logistic Regression Ad Click Prediction

This project uses logistic regression to predict whether a user will click on an ad based on their demographics and browsing behavior.

## Features:
- Daily Time Spent on Site
- Age
- Area Income
- Daily Internet Usage
- Gender

## Tools Used:
- Python
- Pandas, NumPy, Seaborn, Matplotlib
- scikit-learn

## Results:
- Achieved ~90% accuracy
- Younger, high-usage users were more likely to click ads

## How to Run:
1. Clone this repo
2. Install requirements: `pip install -r requirements.txt`
3. Run the Jupyter notebook
